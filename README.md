# care salon 結 LP

care salon 結のスマートフォン向けランディングページです。

## 公開URL

https://lc100068-cmd.github.io/care-salon-musubi/

## 構成

- `index.html` — LP本体とアクセシビリティ情報
- `styles.css` — レスポンシブ表示とLINEボタンのリンク領域
- `script.js` — LINE CTAクリックイベント
- `assets/LP_01.webp`〜`LP_04.webp` — 軽量化したLP画像
- `.github/workflows/pages.yml` — GitHub Pagesへの自動デプロイ

`main` ブランチへの更新時にGitHub Pagesへ自動デプロイされます。
